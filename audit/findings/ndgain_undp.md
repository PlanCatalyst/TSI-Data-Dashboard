## ND-GAIN

- Published composite `resources/vulnerability/vulnerability.csv`: 192 countries, years 1995-2024 (2024 present; SCORING_AUDIT says 1995-2023, stale vs this 2026 release). `ndgain/records.csv` is the same table stacked with an `indicator` column; its `vulnerability` rows were not used separately.
- Methodology (codebook + empirical): each sector = equal-weight mean of its six `id_<sector>_NN` score.csv files; vulnerability = equal-weight mean of the six sectors (food, water, health, ecosystems, habitat, infrastructure). Scores are already 0-1 with higher = more vulnerable (no inversion needed).
- Sector recomposition from indicators vs published sector files (max abs diff, cells compared):
  - food: 6 indicators, max diff 6.66e-16, 5760 cells
  - water: 6 indicators, max diff 6.66e-16, 5760 cells
  - health: 6 indicators, max diff 7.77e-16, 5760 cells
  - ecosystems: 6 indicators, max diff 6.66e-16, 5760 cells
  - habitat: 6 indicators, max diff 6.66e-16, 5760 cells
  - infrastructure: 6 indicators, max diff 5.55e-16, 5760 cells
- Composite recomposed from sectors vs published: 5700 country-years compared, max abs diff 8.58e-02, cells with diff > 1e-9: 1020. Expected scores (0.1 rounding) that differ: 847.
- Published null but recomposable: 60. Published value but not recomposable: 0. Details in `audit/findings/ndgain_undp_diag.csv` (recomposed value is NaN if any sector is missing).
- Conclusion: published composite and recomposition agree to floating-point precision. The expected row uses the published composite.

## MPI

- Source: `sheets/mpi__gMPI_Table2.csv` (harmonized estimates over time, comparable across waves), matching SCORING_AUDIT/yaml (88 countries, 1-3 waves). Table 1 (latest survey, 2013-2024) is not used: values differ from Table 2 for the same survey (e.g. Afghanistan 2022/2023: Table 1 0.3603, Table 2 0.268 harmonized) and the pipeline docs use Table 2. Using Table 2 means the latest wave is not the Table 1 headline estimate. Flag for reviewer.
- Year choice: survey END year ("2015/2016 D" -> 2016, "2019 M" -> 2019). Reason: the last field date is the latest time the data describes. Alternative (start year) would shift two-year surveys by one year; a midpoint is undefined for integer years. Matches pipeline doc (survey-end year). Survey code (D/M/N) kept in `note`.
- Waves emitted: 244 over 88 countries. MPI values of 0 or below handled as need 0 (score 100): 0.
- Not an annual panel: sparse by design; no interpolation or carry-forward.
