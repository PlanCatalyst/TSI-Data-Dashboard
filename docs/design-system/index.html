Dashboard Design System

The visual language and motion rules for the dashboard, derived from plancatalyst.org. Square, white, blue for action, green for accent, structure carried by type and 1px rules. This page is the implementation source: its token block is the token file.

Principles
Square

Radius is 0 everywhere. Only dots and avatars are circles. The site has no rounded container.

White sheet

Surfaces are white on a cool off-white ground. No colour slabs, no shadows on content. Tooltips and menus are the only floating elements.

Blue acts, green accents

Blue is the only interactive colour. Green appears as a positive mark or an accent word, never as a button fill.

Type carries structure

Hierarchy comes from Montserrat headings, tracked eyebrows and 1px rules. Not from boxes.

Need is semantic

Need bands use their own cool-to-warm set. They never borrow the brand colours, so "moderate" cannot read as "PlanCatalyst green".

Motion settles

Reveals glide in over a second and settle. Layout moves ease both ways. Nothing pops, springs or bounces.

Expanded: the trend chart and indicator table get the room. Close from here resets the width too.

The panel animates its width; the map takes the rest. D3 re-projects once on transitionend. Close always returns the map to full width, which is bug B1 in the live dashboard today.

Map hover and selection · 200ms fill, outline on select

No pulse, no glow. The selected country gets a dark outline and keeps it until deselected. The choropleth itself is not rebuilt. WorldChoropleth.tsx stays; it only reads its fills, stroke and hover duration from tokens. Everything around it (legend, tooltip, panel, nav) is what changes.

Reduced motion

With prefers-reduced-motion: reduce, every reveal is instant and in place, layout changes snap, the chart is drawn fully, and the loading bar is static. Nothing is hidden from these users.

# fail on colour literals outside the token file
if grep -rnE '#[0-9a-fA-F]{3,6}\b' dashboard/src --include='*.css' --include='*.ts' --include='*.tsx' \
   | grep -v 'styles/tokens.css'; then echo "hex literal outside tokens.css"; exit 1; fi
# fail on any radius other than 0 or 50%
if grep -rnE 'border-radius:\s*(?!0;|50%)' dashboard/src --include='*.css' -P; then exit 1; fi
