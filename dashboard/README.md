# Dashboard React App

Starter React app for the PlanCatalyst frontend implementation.

## Quick start

```zsh
npm install
npm run dev
```

## Contract mount

Set `VITE_CONTRACT_BASE_URL` in `.env` (or use local `/v1` default) and ensure
the app can fetch:

- `meta.json`
- `countries.json`
- `timeseries.json`
